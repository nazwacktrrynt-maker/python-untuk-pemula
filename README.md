# Python untuk Pemula

Latihan dari kursus Python untuk Pemula (Santrikoding).

## Materi yang dipelajari
- Program pertama (print)
- Variabel dan tipe data
- Operator
- Kondisional (if else)
- Perulangan (for dan while)
- Fungsi

## Cara menjalankan
1. Aktifkan virtual environment: `venv\Scripts\activate`
2. Jalankan program, misalnya: `python variabel.py`

Screenshot hasil ada di folder `screenshots/`.
